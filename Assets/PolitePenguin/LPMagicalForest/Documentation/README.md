## Overview

This package contains a collection of low-poly forest assets for Unity, including trees, bushes, plants, mushrooms, rocks, logs, stumps, branches, grass, leaf piles, and decorative runestones.

## Unity Version

Tested with Unity: 6000.4.3f1

## Render Pipeline

Supported render pipelines:

- Built-in Render Pipeline
- Universal Render Pipeline

The main imported package is prepared for the Built-in Render Pipeline.

A separate URP version is included as an additional `.unitypackage` file inside this package.

Do not import both versions into the same project unless you intentionally want to manage both render pipeline versions manually.

## URP Setup

If you are using the Universal Render Pipeline, import the included URP `.unitypackage` version.

After importing the URP version, make sure a URP Render Pipeline Asset is assigned in your project settings.

To assign it:

1. Go to `Edit > Project Settings > Graphics`.
2. Assign the included `LP_MagicalForest_URP` asset to the `Scriptable Render Pipeline Settings` field.
3. Also check `Edit > Project Settings > Quality`.
4. Assign the same URP asset for the active quality level if needed.

If materials appear pink or the scene does not render correctly, the project is likely missing the correct URP setup.

After assigning the URP settings, reopen the demo scene if necessary.
